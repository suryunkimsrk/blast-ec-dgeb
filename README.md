# BLAST EC Classification
SP26 CS690 Computational Biology and Bioinformatics
Final Project (S. Kim)

## Description
Evaluating BLAST performance vs. foundation models 
on the EC Amino Acid classification task from DGEB.

## Data
EC classification dataset from HuggingFace:
[https://huggingface.co/datasets/tattabio/ec_classification/tree/main/data]

## Requirements
- NCBI BLAST+ 2.17.0 : [https://ftp.ncbi.nlm.nih.gov/blast/executables/blast+/LATEST/]
- Python (pandas, sklearn)

## Usage
Run `blast_ecclassify_SK.ipynb`
